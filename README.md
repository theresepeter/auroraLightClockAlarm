Aurora is a light alarm clock that was implemented using an ESP32. The code was written in C++ and the housing was 3D-printed.

The aim of this project was to combine several electronic components with the ESP32 and develop an innovative idea.
This also included designing an intuitive user interface and defining a suitable target group.

The components used in the light alarm clock are:
- Buttons for operation
- Rotary encoder for setting the alarm times
- LED ring that simulates a sunrise
- OLED display for showing the time
